# 🌐 DevFolio Web

> **A modern, responsive, developer-focused portfolio website highlighting AI/ML engineering projects, system architectures, and technical competencies.**

---

## ✨ Features

- **Engineering First**: Clean dark-mode UI highlighting project cards with architecture tags, tech stacks, and live GitHub repo links.
- **Pure HTML5 & CSS3**: Zero heavy frameworks, zero runtime dependencies, sub-second load times.
- **Mobile Responsive**: Flexbox & CSS Grid layouts optimized for desktops, tablets, and mobile devices.
- **GitHub Pages Ready**: Can be deployed with one click by pushing to a repository named `<your-username>.github.io` or enabling GitHub Pages on `main`.

---

## 🚀 Quickstart

Simply open `index.html` in any web browser, or host via GitHub Pages!
